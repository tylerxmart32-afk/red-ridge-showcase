# Red Ridge Showcase

I need a professional reference/portfolio page for Red Ridge AI  - a B2B AI consulting firm serving SMBs. This is a trust-building page to show prospects  the companies we’ve worked with and services we offer.
Design Requirements:
	•	Dark theme (slate 950 background, professional)
	•	Modern, premium look (not templated)
	•	Mobile responsive
	•	Fast loading
Page Sections:
	1.	Top Navigation - Red Ridge logo + CTA button
	2.	Hero Section - Headline “AI Infrastructure for Growing SMBs” + subheadline about revenue recovery + 2 CTAs (Schedule Demo, Call) + placeholder for professional headshot photo + quick stats (24/7 automation, 5+ years)
	3.	Services Grid - 6 service cards with icons:
	•	Voice & Chat Agents (with icon for messaging)
	•	Website Development (with globe icon)
	•	AI Automations (with cog icon)
	•	Backend & Database (with database icon)
	•	Social Media Management (with trending icon)
	•	SEO & Marketing Automation (with zap icon)
Each card should have: icon, title, description, 3 key features listed with checkmarks
	4.	Social Proof Section - “Companies We’ve Transformed” headline + Grid of clickable client logos
	•	Each logo card shows: company name, 2-3 services provided, clickable link to their website
	•	Use initials (e.g., “AC” for Automotive Creations) with company brand color background
	•	Hover effect that brightens the card and shows arrow
	•	Include at least 3 placeholder logos (we’ll customize with real clients)
	5.	Bottom CTA - “Ready to Deploy?” section with gradient background + 2 buttons (Schedule Discovery, Send Requirements)
	6.	Footer - Logo, links to services, company info, contact details, copyright
Colors:
	•	Primary: Red 600 (#DC2626)
	•	Secondary: Black 
	•	Background: Slate 950 (#030712)
	•	Text: White + Slate 400
	•	Borders: Slate 700 with red hover states
Interactive Elements:
	•	Smooth hover effects on service cards (border highlight, background change)
	•	Logo cards light up on hover with company details
	•	Buttons have hover states
	•	Smooth transitions throughout
Content to Include:

	•	Tagline: “Revenue recovery, not tech experiments”
